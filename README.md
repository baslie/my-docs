# my-docs

Коллекция полезных материалов, опубликованных через GitHub Pages.

## $1M Attention

Статья **«$1M Attention»** — гайд по привлечению внимания к MVP (инжиниринг внимания, «attentioneering»): фреймворк LEHI и 17 проверенных форматов постов.

**Читать онлайн:** [baslie.github.io/my-docs](https://baslie.github.io/my-docs/)

Страница собирается автоматически из этого репозитория средствами GitHub Pages (ветка `main`, корень `/`). Исходник — [`index.html`](index.html), изображения — в папке [`images/`](images/).
